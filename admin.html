投稿の承認ModerationModération

コメント・注釈・誤りの指摘は「承認待ち」で届きます。内容を確認して〈承認〉すると公開され、〈却下〉すると投稿者本人にだけメモ付きで表示されます。公開済みの投稿を投稿者が修正したときは〈修正の申請〉に届き、承認するまでは元の内容が公開されたままになります。〈メッセージ〉には、プロフィールページから送られたバグの報告と応援メッセージが届きます（公開されません）。Comments, annotations and corrections arrive as “pending”. Approve to publish; reject to keep it private (the author sees your note). When an author edits a published contribution it arrives under “Revisions”, and the original text stays online until you approve the change. “Messages” holds the bug reports and messages of support sent from the profile page (never published).Les contributions arrivent « en attente ». Approuver les publie ; rejeter les garde privées (l’auteur voit votre note). Lorsqu’un auteur modifie une contribution publiée, la demande arrive sous « Révisions » et le texte d’origine reste en ligne jusqu’à votre approbation. « Messages » réunit les signalements de bogues et les messages d’encouragement envoyés depuis la page de profil (jamais publiés).

データベースの更新が必要です。〈修正の申請〉と〈メッセージ〉（およびブックマーク）を使うには、Supabase の SQL Editor で supabase/schema.sql の全体をもう一度実行してください（既存のデータは消えません）。The database needs updating. To use “Revisions” and “Messages” (and bookmarks), run the whole of supabase/schema.sql again in the Supabase SQL Editor (existing data is kept).La base de données doit être mise à jour. Pour utiliser « Révisions » et « Messages » (et les marque-pages), exécutez de nouveau l’intégralité de supabase/schema.sql dans le SQL Editor de Supabase (les données existantes sont conservées).
